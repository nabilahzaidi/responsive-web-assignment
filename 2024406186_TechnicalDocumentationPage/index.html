Introduction

Calculus I is a fundamental branch of mathematics focusing on rates of change and accumulation. It is divided into two primary subfields: differential calculus and integral calculus.

Inside a analytical framework, calculus utilizes limits to provide programmatic and precise control over complex continuous functions where standard algebra fails.

Calculus contains a standard library of concepts, such as functions, limits, derivatives, and integrals, which form a core set of elements for scientific models. Core calculus can be extended for a variety of purposes by supplementing it with multi-variable systems; for example:

  • Theoretical math extends core ideas by supplying proofs to control bounds and intervals. For example, rigorous epsilon-delta frameworks allow an analyst to pinpoint values exactly.
  • Applied engineering extends core calculations by supplying formulas relevant to running models on dynamic real-world hardware systems.

Limits and Continuity

Definition of the Derivative

The derivative of a function represents its instantaneous rate of change at a given point. Graphically, it translates directly to the slope of the tangent line to the curve.

This instantaneous value is derived by calculating the limit of secant line slopes over an interval value approaching zero.

f'(x) = lim(h -> 0) [f(x+h) - f(x)] / h
Rules of Differentiation

Evaluating limits manually for every equation is highly repetitive. A set of algebraic rules facilitates rapid differentiation for common operations.

These rules establish predictable patterns when dealing with exponents, products, and complex inner function layers.

  • Power Rule maps scaling steps across power factors.
  • Product and Quotient Rules handle joint structures smoothly.
  • Chain Rule manages composite layered function sets cleanly.
d/dx [x^n] = n * x^(n-1)
